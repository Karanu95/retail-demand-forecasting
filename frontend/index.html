About This Project

Technical overview of the retail demand forecasting system.

Dataset

Synthetic daily aggregate retail demand data spanning 2022-01-01 to 2024-01-01 (730 days). Covers total units sold across all stores and product categories. The final 30 days were held out for evaluation.

Feature Engineering

12 time-series features including lag values (1, 7, 14, 28 days), rolling means (7- and 28-day windows), and calendar encodings — day of week, month, cyclic day-of-year sine/cosine.

Model Selection

Nine models were evaluated per horizon using rolling-origin cross-validation with 7 folds. Random Forest was selected for 7-day forecasts and Extra Trees for 30-day forecasts based on lowest mean MAE.

Validation Methodology

Rolling-origin cross-validation simulates real forecasting by training on progressively larger windows. 7 origins spanning May–October 2023 were used. Each fold generates a full 7- or 30-day forecast for evaluation.

Technology Stack

Backend: FastAPI (Python) deployed on Render. Machine learning via scikit-learn. Frontend: vanilla HTML, CSS and JavaScript. Hosted on Netlify. No build tools or frameworks.

Important Caveat

The dataset is synthetic, ending 1 January 2024. Forecasts generated here are model demonstrations, not live retail predictions for 2026. Negative R² values on validation data reflect the challenging, noisy nature of aggregate demand forecasting.
